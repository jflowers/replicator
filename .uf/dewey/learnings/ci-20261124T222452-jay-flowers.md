In GitHub Actions, when a workflow provides a required status check and you want to skip its expensive jobs for some PRs, do NOT use `paths`/`paths-ignore` (a workflow that never runs never reports the check, leaving PRs stuck in \"Expected — Waiting\"). Instead: (1) add a cheap detection job that outputs a boolean, (2) gate expensive jobs with `needs:` + `if:`, and (3) add an `if: always()` aggregate job whose name is the required check and which fails on `contains(needs.*.result, 'failure')` or `'cancelled'`. The aggregate is mandatory when a gated job is a reusable-workflow call, because a skipped reusable call reports only the caller's name and never emits its nested checks. Fail the detection job closed (exit non-zero on diff errors) so a broken detector blocks rather than silently skips.
